## Project Overview

This repository contains the initial website development project for **Ubuntu Tech Solutions (UTS)**, an IT support and computer services company based in Durban, KwaZulu-Natal. The company was founded in 2021 by two IT graduates and provides on-site and remote technical support to small businesses, schools, and residential clients throughout the greater Durban area.

The name "Ubuntu" reflects the African philosophy of "I am because we are," which guides the company's approach to client relationships: technology should bring people together and empower communities, not create barriers.

---

## Website Goals and Objectives

1. **Build Trust & Technical Authority:** Establish UTS as a credible, professional IT partner through polished design, case studies, and certification displays.
2. **Generate B2B Leads:** Capture qualified leads through service-specific landing pages targeting local Durban and KwaZulu-Natal search queries.
3. **Enable Online Service Booking:** Allow clients to schedule on-site visits or remote support sessions directly through the website.
4. **Reduce Phone Support Load:** Empower clients to resolve common issues independently via a comprehensive knowledge base and FAQ section.
5. **Support Business Scalability:** Provide a careers page and scalable architecture for future growth, including potential e-commerce functionality.
6. **Ensure POPIA Compliance:** All data collection forms comply with South Africa's Protection of Personal Information Act.

---

## Key Features and Functionality

### Core Website Pages
- **Homepage (`index.html`):** Value proposition hero section, service overview cards, trust badges, emergency support CTA, and service area coverage.
- **About Us (`about.html`):** Company origin story rooted in the Ubuntu philosophy, team profiles with certifications, mission and vision statements, and community involvement initiatives.
- **Services (`services.html`):** Dedicated pages for Computer & Laptop Repairs, Network Installation & WiFi, Managed IT Support, Cybersecurity Audits, Cloud Migration, and IT Consulting.
- **Book a Service (`enquiry.html`):** Online booking form with service type selection, preferred date/time, issue description, and POPIA consent checkbox.
- **Contact (`contact.html`):** Multiple contact methods (phone, email, WhatsApp), embedded map placeholder, emergency hotline banner, secondary office location, and quick contact form.

### Technical Features
- Fully responsive, mobile-first design optimised for South African mobile data users
- Semantic HTML5 structure using `header`, `nav`, `main`, `section`, `article`, and `footer` tags
- External CSS stylesheet for consistent branding and layout
- External JavaScript file for form validation, navigation highlighting, and smooth scrolling
- Cross-browser compatible HTML code with proper indentation and inline comments
- Navigation menu functioning correctly across all five web pages
